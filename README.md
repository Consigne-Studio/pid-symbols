# pid-symbols (édition gratuite)

30 symboles SVG courants pour schémas de procédé (P&ID) et écrans de supervision, sous licence MIT : vannes, pompes, cuves, échangeurs, instruments et lignes.

* Grille 48 × 48, trait 2 px, couleur héritée (`currentColor`) : clair ou sombre sans retouche.
* SVG et PNG 256 px transparents. Classes d'état dans `pid-symbols.css` (`is-running`, `is-fault`…).

## Édition complète

117 symboles en 11 familles (dont traitement d'eau, CVC, électricité, boucles de régulation), 468 PNG, sprite, bibliothèque draw.io, module JavaScript et animations : https://consignestudio.fr/en/pid-symbols-svg/.
